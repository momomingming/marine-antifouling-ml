# 海洋防污材料ML预测平台 — 方法说明书

**版本**: v2.0 | **日期**: 2026-08-23 | **数据集规模**: 1158条 (486条文献 + 672条增强)

## 1. 平台概述

本平台的核心理念是**可解释性优先**:
- ❌ 不使用黑箱模型 (如深度神经网络)
- ✅ 所有预测均可追溯到具体的物理化学原因
- ✅ 20%数据作为盲测集，训练时完全不可见
- ✅ 多种模型对比，明确哪种方法最有效

## 2. 分子描述符说明

输入SMILES分子结构后，平台自动计算以下描述符:

| 描述符 | 物理含义 | 与防污的关系 |
|--------|---------|------------|
| MW | 分子量 (g/mol) | 影响涂层力学性能和成膜性 |
| LogP | 辛醇-水分配系数 | 衡量疏水性，影响表面能 |
| TPSA | 拓扑极性表面积 (Å²) | 极性越大亲水性越强 |
| HBD/HBA | 氢键供体/受体数 | 影响水化层形成 |
| RotBonds | 可旋转键数 | 链柔性，影响弹性模量 |
| NumF | 氟原子数 | 氟显著降低表面能 |
| NumSi | 硅原子数 | 硅氧烷降低表面能和模量 |
| ChargeDensity | 电荷密度 | 两性离子防污的关键 |
| SurfaceEnergyEst | 表面能估计 | 低表面能→高脱附率 |
| ElasticModulusEst | 弹性模量估计 | 低模量→低断裂能→易脱附 |
| CrosslinkPotential | 交联潜力 | 影响涂层耐久性 |

## 3. 机器学习模型详细说明

### 3.1 决策树回归 (Decision Tree Regressor)

- **原理**: 通过递归二分特征空间构建预测树。每个叶节点对应一个预测值，从根到叶的路径即为决策规则。
- **优势**: 完全可解释：每条预测都可追溯为if-then规则链
- **局限**: 容易过拟合，单棵树泛化能力有限
- **超参数**: max_depth=6, min_samples_split=10, min_samples_leaf=5
- **可解释性**: ★★★★★ (最高)

### 3.2 岭回归 (Ridge Regression)

- **原理**: 在线性回归基础上添加L2正则化，防止系数过大。系数大小直接反映特征对目标的影响方向和强度。
- **优势**: 系数稳定，可解释性强，计算快速
- **局限**: 只能捕捉线性关系
- **超参数**: alpha=1.0 (正则化强度)
- **可解释性**: ★★★★★ (最高)

### 3.3 Lasso回归 (L1正则化)

- **原理**: 使用L1正则化进行特征选择，将不重要特征的系数压缩为0。非零系数即为关键特征。
- **优势**: 自动特征选择，稀疏解更简洁
- **局限**: 可能遗漏相关特征
- **超参数**: alpha=0.1 (正则化强度)
- **可解释性**: ★★★★★ (最高)

### 3.4 K近邻回归 (K-Nearest Neighbors)

- **原理**: 预测值等于K个最近训练样本的目标值加权平均。可追溯具体是哪些样本影响了预测。
- **优势**: 无需假设函数形式，预测可追溯到具体样本
- **局限**: 计算量大，对高维数据敏感
- **超参数**: n_neighbors=5, weights=distance
- **可解释性**: ★★★★☆ (高)

### 3.5 XGBoost梯度提升树

- **原理**: 通过迭代训练多棵决策树，每棵树修正前一棵的残差。特征重要性反映各特征对预测的总贡献。
- **优势**: 预测精度高，可处理非线性关系
- **局限**: 单棵树可解释，但集成后解释性降低(通过SHAP补偿)
- **超参数**: n_estimators=200, max_depth=5, learning_rate=0.05
- **可解释性**: ★★★☆☆ (中，需SHAP辅助)

### 3.6 加权集成模型 (Weighted Ensemble)

- **原理**: 将多个基础模型的预测按权重组合。权重由各模型交叉验证性能决定。最终预测 = Σ(wi × predi)
- **优势**: 综合各模型优势，鲁棒性最强
- **局限**: 整体解释性取决于各子模型
- **超参数**: 权重由CV性能自动确定
- **可解释性**: ★★★☆☆ (中)

## 4. 盲测验证机制

### 4.1 数据分割策略
- **训练集 (80%)**: 用于模型训练和超参数选择
- **盲测集 (20%)**: 完全保留，训练时不可见
- **分割方式**: 分层随机抽样，保证各类别比例一致

### 4.2 验证流程
1. 所有模型仅在训练集上训练
2. 5折交叉验证在训练集内部进行
3. 盲测集仅在所有训练完成后使用一次
4. 报告盲测R²、MAE、RMSE作为真实性能指标

### 6.2 综合结论

1. **XGBoost** 在大多数目标上表现最佳，因为它能捕捉非线性关系和特征交互
2. **Ridge/Lasso** 在数据量充足时表现稳定，且提供最有价值的特征贡献信息
3. **Decision Tree** 提供直观的决策规则，适合快速筛选
4. **集成模型** 综合各模型优势，在多数情况下鲁棒性最强
5. **KNN** 在局部结构相似的区域预测准确，但泛化能力有限

### 6.3 推荐预测策略
- **初筛**: 使用Decision Tree快速判断材料类别
- **精筛**: 使用XGBoost获得精确性能预测
- **机理解释**: 使用Ridge系数理解各特征的贡献
- **最终决策**: 参考集成模型的综合评分

## 8. 局限性声明

1. **数据增强**: 部分数据基于物理约束生成，非直接实验测量
2. **SMILES近似**: 纳米粒子、复合材料用简化SMILES表示
3. **描述符局限**: 无法完全捕捉表面形貌、微观结构等信息
4. **环境因素**: 未考虑海水温度、盐度、流速等环境因素
5. **长期性能**: 预测基于短期实验数据，长期耐久性需额外验证
